# Ojectif du projet
Implémenter les techniques de reduction de dimension:L'Analyse en Composantes Principales(ACP) et la TSNE.La première est une methode linéaire tandis que la TSNE est capacable de detecter des correlations complexes non linéaires.
# Dataset utilisé
Le dataset SVHN qui est un jeu de données d'images 
# Challenge
Le SVHN est trés bruité ce qui  fait que meme la TSNE qui est très sophistiqué n'a pas permis de detercter les clusters.L'alternative est de jouer sur le constraste des images afin d'éliminer les redondances.
